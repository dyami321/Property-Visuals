Picture it

Illustrated posters: cartoon-style cards that turn each rule into a memorable image, plus comic storyboards for the hypos.

How to read a poster: each card has a title tab, a picture, and a caption stating the rule. Check marks and crosses show which side wins; badges flag the factor that decides; dashed lines mark a boundary; a question mark means the sources leave it open. Pictures simplify the facts, so the figure notes under each poster say where a detail is my own reading.
